# FutHub – Futsal Booking & Matchmaking App

FutHub is a full‑stack application designed to make futsal more accessible and organized. It connects players and futsal owners with a streamlined booking system, while also helping teammates and opponents find each other for matches.

---

## 🌐 Live Demo
- Frontend (Netlify): https://futhub.netlify.app
- Backend (Render): https://futhub.onrender.com

---

## 🔹 Key Features
- Court Booking → Reserve futsal time slots quickly; owners manage availability.
- Teammate & Opponent Finder → Matchmaking system to connect players for games.
- Admin Dashboard → Approve/reject bookings, track schedules, and manage users.
- Transparent Workflows → Clear approval and cancellation logic for bookings.
- User Feedback → Players share experiences to build trust.
- Modern UI → Responsive design with React, SCSS, and Material UI.

---

## 🔹 Tech Stack
- Frontend: React, Vite, SCSS, Material UI
- Backend: Node.js, Express.js
- Database: MongoDB
- Other Tools: SweetAlert, Nodemon, JWT Authentication
